# Point Verify (취입 검사대)

## 개요
\point-verify.html\은 데이터 파이프라인이 벤더의 PDF 문서에서 추출해 낸 장비 포인트(통신 접점) 목록을, **실제 원본 PDF의 해당 페이지(그림/표)와 나란히 대조(Side-by-side)**하여 검증하는 화면입니다.

## 역할 및 목적
- **파이프라인 신뢰성 검증:** 기계(파이썬 스크립트)가 PDF 표에서 올바르게 데이터를 긁어왔는지 사람이 눈으로 확인합니다.
- **오차 원인 추적:** PDF의 인쇄 쪽 번호(Page number)와 논리적 인덱스가 달라서 발생하는 문제나, 헤더(머리글) 파싱 오류, 각주(Footnote) 누락 등 기계적 추출의 한계를 사람이 보완합니다.
- 추출 코드를 수정하면 기존 방식과 동일한 맹점을 통과할 수 있기 때문에, 다른 시각적 경로(이미지 렌더링)로 교차 대조(Crosscheck)하는 것이 핵심입니다.

## 동작 방식
1. \erify_points.py\가 실행되면 각 모델에 대해 원문 PDF의 인쇄 쪽 번호를 스캔합니다.
2. 매칭되는 페이지를 이미지로 자르거나 렌더링합니다.
3. 기계가 추출한 포인트 목록 표와 실제 PDF 캡처 이미지를 HTML 상에 나란히 렌더링합니다.

## 주의 사항
이 HTML 파일은 렌더링된 캡처 이미지를 포함하기 때문에 용량이 매우 큽니다 (약 17~18MB). 따라서 Git 저장소에는 원본 바이너리를 올리지 않고 무시(\.gitignore\)되도록 처리됩니다.
